# Jardín de barrio · Bogotá 2026

Estudio navegable de prefactibilidad para abrir un jardín infantil privado pequeño en un inmueble arrendado en Bogotá. El escenario base usa 30 cupos, atención de 24 a 60 meses y una ubicación de referencia en Villa Luz/Engativá.

## Qué incluye

- decisión regulatoria SDIS vs. SED;
- comparación preliminar entre Engativá, Kennedy y Suba;
- estructura de personal para 15, 25, 30 y 35 niños;
- inversión, costos, flujo mensual a 24 meses y escenarios;
- calculadora editable de punto de equilibrio;
- debida diligencia del inmueble, cronograma, riesgos y puertas de decisión;
- fuentes oficiales y comparables de mercado consultados el 3 de agosto de 2026.

## Desarrollo local

No requiere dependencias externas.

```bash
npm run build
npm test
npm run dev
```

El servidor local abre `dist/` en `http://localhost:4173`.

## Publicación

El workflow `.github/workflows/pages.yml` construye y publica el sitio en GitHub Pages al hacer push a `main`.

## Alcance y advertencia

El contenido es un estudio preliminar con supuestos explícitos; no sustituye concepto escrito de la SDIS, SED, Planeación, Salud, Bomberos, IDIGER ni asesoría profesional. No se debe firmar el arrendamiento ni iniciar adecuaciones hasta verificar el uso permitido, la licencia del inmueble, el riesgo del predio y la ruta regulatoria aplicable.
